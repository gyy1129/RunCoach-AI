# 疼痛排查与康复技能

## 触发条件

当用户报告以下情况时激活：
- 跑步后出现疼痛
- 身体任何部位不适
- 运动损伤排查
- 康复训练指导需求

**重要声明**：本技能提供的建议基于运动康复经验，不是医学诊断。如出现严重症状，请立即就医。

## 工作流程

### 1. 读取上下文

1. 读取 `context/person.md` 获取训练者既有身体状况
2. 读取 `context/thought.md` 获取规则
3. 读取 `logs/` 目录下最近3-7天的训练日志
4. 读取 `plans/` 目录下当前训练计划

### 2. 疼痛信息收集

如果用户未提供完整信息，引导用户补充：
- **疼痛位置**：具体哪个部位？（左/右/中间）
- **疼痛类型**：刺痛/钝痛/酸痛/灼烧感/麻木/放射痛
- **出现时间**：训练中/训练后/第二天早上/持续
- **严重程度**：0-10分（0=无疼痛，10=无法忍受）
- **加重因素**：什么动作会让疼痛加剧？
- **缓解因素**：什么方法能减轻疼痛？
- **伴随症状**：肿胀/发热/麻木/活动受限

### 3. 紧急判断（就医红线）

如出现以下任一情况，**立即建议就医**：
- 疼痛评分 ≥ 7/10
- 出现放射痛（如从腰部放射到腿部）
- 出现麻木感或针刺感
- 关节明显肿胀或变形
- 无法承重行走
- 疼痛持续超过48小时无缓解
- 夜间静息痛（不活动时也痛）
- 腰间盘突出相关：腿部无力、大小便异常（急诊）

### 4. 诊断分析

基于疼痛信息和近期训练数据，分析可能原因：

#### 膝内扣相关
- **髌股疼痛综合征**：髌骨下方疼痛，上下楼梯加剧
- **髂胫束综合征**：膝外侧疼痛，常见于跑量突增
- **原因排查**：步频是否<175？是否跑前未做臀中肌激活？是否跑下坡？跑鞋是否磨损严重？

#### 膝超伸相关
- **髌腱炎**：髌骨下方肌腱疼痛
- **鹅足滑囊炎**：膝内侧下方疼痛
- **原因排查**：落地是否冲击过大？是否股四头肌过度紧张？是否步幅过大？

#### 脚踝不稳相关
- **跟腱炎**：脚后跟上方疼痛，晨起加重
- **足底筋膜炎**：脚底疼痛，晨起第一步最痛
- **踝关节外侧疼痛**：反复微扭伤
- **原因排查**：是否在倾斜路面跑步？跑鞋是否缺乏支撑？是否跳过单腿平衡训练？

#### 腰间盘突出相关
- **腰部肌肉紧张**：腰部僵硬、酸痛
- **坐骨神经痛**：从腰部放射到臀部或大腿后侧
- **骶髂关节问题**：臀部单侧疼痛
- **原因排查**：是否跳过核心激活？跑姿是否过度前倾？跑后是否做了深度前屈？是否连续高冲击日？

#### 其他常见跑步疼痛
- **胫骨应力综合征**：小腿前侧疼痛（跑量突增、硬路面）
- **足底筋膜**：脚底疼痛（鞋支撑不足、足弓问题）
- **髋部疼痛**：髋屈肌紧张（久坐+跑步）

### 5. 关联近期训练

检查最近3-7天的训练日志：
- 跑量是否突增？（超过上周10%）
- 是否新增训练类型？（如第一次间歇跑）
- 是否路面变化？（从塑胶跑道到水泥路）
- 是否跑鞋更换？
- RPE 是否异常升高？
- 睡眠/精力是否明显下降？

### 6. 输出建议

必须包含以下内容：

#### 立即处理
- **停止/继续训练**的明确建议
- **即时处理措施**：冰敷/热敷/拉伸/泡沫轴（具体到部位、时间、频率）
- **48小时内注意事项**

#### 康复训练
- 具体的康复动作、组数、次数、频率
- 针对训练者身体条件的个性化康复（考虑膝内扣/超伸/脚踝/腰部问题）

#### 训练调整
- 修改后的训练计划（降级/替代/暂停）
- 何时可以恢复原训练的判断标准
- 恢复训练的渐进方案

#### 回归时间
- 预计恢复时间范围
- 每阶段可以做什么

#### 就医标准
- 什么情况下必须看医生
- 建议就诊科室
