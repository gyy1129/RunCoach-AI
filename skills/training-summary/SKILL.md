# 训练总结技能

## 触发条件

当用户要求以下操作时激活：
- 本周训练总结
- 本月训练总结
- 周度/月度训练回顾
- 训练数据汇总

## 工作流程

### 1. 读取上下文

1. 读取 `context/person.md` 获取训练者信息
2. 读取 `plans/` 目录下对应的训练计划
3. 读取 `logs/` 目录下指定时间范围内的所有训练日志
   - 周总结：最近7天
   - 月总结：最近30天

### 2. 数据统计

计算以下指标：
- **总跑量**：本周/月总公里数
- **总训练次数**：各类训练课次统计
- **训练类型分布**：轻松跑/节奏跑/间歇跑/LSD/交叉训练/力量/休息 各占比例
- **平均配速**：所有跑步课次的加权平均
- **平均心率**：有氧训练课次的平均心率
- **平均步频**：跑步课次的平均步频
- **计划完成率**：实际完成课次 / 计划课次
- **疼痛/不适次数**：出现身体不适的训练课次
- **平均RPE**：主观用力程度均值

### 3. 对比分析

将实际数据与计划对比：
- 跑量偏差：实际 vs 计划
- 强度分配：实际 70/20/10 vs 目标比例
- 完成质量：配速是否达标、心率是否在预期区间

### 4. 亮点与问题

总结：
- **最佳课次**：表现最好的一次训练（配速、心率、RPE综合判断）
- **最差课次**：表现最差或出现不适的训练
- **疼痛事件**：所有出现疼痛/不适的记录
- **显著进步**：可量化的改进（如同样配速心率下降X bpm）
- **需关注问题**：持续出现的不良趋势

### 5. 下阶段建议

基于总结给出：
- 保持什么（做得好的方面）
- 调整什么（需要改进的方面）
- 重点关注（身体、技术、心理）
- 下阶段目标

### 6. 输出路径

将总结写入 `summary/` 目录：
- 周总结：`summary/week(MMDD-MMDD).md`
- 月总结：`summary/month(MMDD-MMDD).md`
- 阶段性总结：`summary/phase(名称-MMDD-MMDD).md`
