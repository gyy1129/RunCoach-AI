# 训练计划生成技能

## 触发条件

当用户要求以下操作时激活：
- 生成训练计划
- 更新/修改训练计划
- 根据训练情况调整计划
- 制定新的训练周期计划

## 工作流程

### 1. 读取上下文

1. 读取 `context/person.md` 获取训练者信息
2. 读取 `context/thought.md` 获取规则
3. 读取现有计划 `plans/` 目录下的最新计划文件（如有）
4. 读取 `logs/` 目录下最近的训练日志（最近7天）

### 2. 状态分析

基于读取的信息分析：
- 当前训练进度（相对于计划）
- 配速趋势（提升/持平/下降）
- 心率趋势（同等配速下心率下降 = 进步）
- 疼痛/不适频率
- RPE 趋势（同等训练是否感觉更轻松）
- 生理期影响

### 3. 应用规则

必须遵守以下规则：
- **疼痛优先级**：疼痛 > 训练计划
- **强度分配**：70% 低强度 / 20% 节奏 / 10% 间歇
- **跑量增长**：每周增长 ≤ 10%
- **交叉训练**：可替代低强度跑或恢复，不替代跑步专项训练
- **允许调整**：配速 ±10s、距离 ±2km、增减恢复日、训练内容调换
- **间歇/节奏类型**：400m/800m/1000m 间歇、分段节奏跑、金字塔间歇、变速跑

### 4. 禁止行为

- 频繁推翻已有计划、删除关键训练
- 忽略用户身体反馈
- 给出模糊建议（如"多休息"）
- 用交叉训练完全替代跑步专项

### 5. 生成计划

输出训练计划到 `plans/` 目录，文件名格式：`YYYY-MM-DD-计划名称.md`

计划必须包含：
1. **状态分析**：当前训练状态评估
2. **调整判断**：为什么需要调整（或为什么保持原计划）
3. **恢复建议与注意事项**：具体的恢复措施
4. **下次训练内容**：详细的训练安排（日期、类型、距离、配速、间歇）
5. **替代方案**：雨天/身体不适/生理期的替代训练

### 6. 身体条件适配

针对训练者的身体条件，计划中必须包含：
- **膝内扣/超伸**：步频目标175+、臀中肌激活、避免下坡
- **脚踝不稳**：稳定跑鞋、避免倾斜路面、单腿平衡训练
- **腰间盘突出**：核心激活必做、避免过度前屈、放射痛立即停止
- **生理期**：经期降强度、卵泡期安排质量课

## 输出格式

```markdown
# 训练计划更新 - YYYY-MM-DD

## 状态分析
[当前状态评估]

## 调整判断
[调整原因或维持原计划理由]

## 恢复建议与注意事项
[具体恢复措施]

## 下周训练内容
[详细训练安排]

## 替代方案
[雨天/不适/生理期的替代训练]
```
