# 训练日志分析技能

## 触发条件

当用户要求以下操作时激活：
- 分析最近的训练日志
- 推荐下次训练内容
- 评估训练效果
- 查看训练进步

## 工作流程

### 1. 读取上下文

1. 读取 `context/person.md` 获取训练者基准信息
2. 读取 `context/thought.md` 获取规则
3. 读取 `plans/` 目录下当前有效的训练计划
4. 读取 `logs/` 目录下最近的训练日志（最近7天为周分析，最近30天为月分析）

### 2. 数据趋势分析

从训练日志中提取并分析：
- **配速趋势**：同类训练的配速变化（提升/持平/下降）
- **心率趋势**：同等配速下心率变化（下降 = 有氧能力提升）
- **RPE 趋势**：同等训练的主观感受变化（降低 = 适应良好）
- **步频趋势**：是否稳定在目标区间（175+）
- **疼痛频率**：膝盖/脚踝/腰部的不适是否增加
- **完成率**：计划完成情况（完成/调整/取消）
- **生理期关联**：经期前后的表现波动

### 3. 训练效果评估

判断训练状态：
- **进步中**：配速提升、心率下降、RPE降低、无疼痛
- **平台期**：数据无明显变化，无疼痛
- **过度训练风险**：RPE升高、心率异常、持续疲劳、疼痛增加
- **需要减量**：多项指标恶化、疼痛>3/10、睡眠变差

### 4. 推荐下次训练

基于分析结果：
- **进步中**：按原计划推进，可适度增加难度
- **平台期**：保持当前强度，给身体更多适应时间
- **过度训练风险**：降低强度或改为交叉训练1-2天
- **需要减量**：主动减量，恢复优先

### 5. 输出

必须包含：
1. **状态分析**：数据趋势总结
2. **调整判断**：为什么推荐某种训练
3. **恢复建议与注意事项**：具体恢复措施
4. **下次训练内容**：详细训练安排
5. **替代方案**：天气/身体不适的替代训练

## 输出格式

```markdown
# 训练分析 - YYYY-MM-DD

## 状态分析
[数据趋势总结：配速、心率、RPE、疼痛情况]

## 调整判断
[推荐依据]

## 恢复建议与注意事项
[具体恢复措施]

## 下次训练内容
[详细训练安排：日期、类型、距离、配速、注意事项]

## 替代方案
[雨天/不适的替代训练]
```
